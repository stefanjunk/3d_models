# Design Multicolor FDM

Load `multicolor-fdm-design` and apply it to the user's request.

Create or update `multicolor-job.yaml`, route companion 3D-design skills as needed, preserve source assets, select the least fragile color representation, produce editable sources and a multi-part 3MF where appropriate, estimate color changes and purge, and provide validation evidence.

Do not assume slicer display colors are physical slot assignments.
