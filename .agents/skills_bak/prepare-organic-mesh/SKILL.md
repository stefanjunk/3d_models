# Prepare Organic Mesh

Load `organic-mesh-functionalization` and apply it to the user's request.

Create a baseline report, determine scale and coordinates, identify mesh defects and components, define ROI/protected/transition/keep-out regions, estimate memory before voxel allocation, create a proxy when needed, and recommend a tool and integration route.

Do not modify the archival source, perform the final destructive edit, or claim that ambiguous regions are safely segmented.
