# Depth, visibility, and structure

For engraving, a conservative starting budget is:

`max_safe_depth = wall_thickness - max(1.2 mm, 3*nozzle_mm)`

Increase reserve for load-bearing or brittle parts.

Typical starting ranges:
- subtle texture engrave: 0.10–0.35 mm;
- readable engraved logo/text/subject: 0.30–0.90 mm;
- visible emboss: 0.50–1.50 mm;
- larger decorative bas-relief: 1.5–3.0 mm when scale and structure allow.

If stronger visual effect is required, increase physical depth or subject size, adjust continuous-tone contrast/gamma, use embossing, or thicken the base wall. Do not posterize the image as a visibility shortcut.
