# Coupon Matrix

| Feature | Required coupon evidence |
|---|---|
| General fit | Male/female clearance ladder in the actual orientation |
| Press fit | Bore/shaft ladder around target size; insertion and retention evidence |
| Heat-set insert | Manufacturer-specific hole ladder, insertion, pull-out/torque as claimed |
| Snap-fit | Actual beam length, taper, root radius, deflection, orientation, cycles |
| Flexure | Actual strain path, cycles, permanent set, failure mode |
| Gear | Tooth fidelity, backlash, torque, speed, wear duration, lubrication condition |
| Seal | Actual mating surface, compression, pressure/fluid/temperature envelope |

Coupons qualify a nozzle/material/process combination. Do not transfer their
compensation values to a different nozzle, material, orientation, or printer
without new evidence.
