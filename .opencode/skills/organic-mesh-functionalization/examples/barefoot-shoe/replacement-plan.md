# Replacement geometry plan

## Complete replacement

Create a lofted `replacement_envelope` around the old sole and a `new_sole` with a matching seam shoulder. Intersect the source with the volume above the seam to retain only the intended upper/skirt, then attach the new sole.

## Skin-preserving replacement

Retain a thin outsole and sidewall band. Derive its inner boundary through an SDF offset or controlled hollowing. Fit the parametric core with adhesive gap and anti-shear keys. Add vents if a closed cavity would remain.

## Reference-only rebuild

Extract the footprint and upper seam curve, discard the old sole geometry, and build a new sole from measured constraints. This gives the best control of zero drop, thickness, toe box, flex, and attachment.

## Validation

- section every 10–20 mm along the length;
- inspect core/skin overlap and voids;
- confirm upper flange continuity;
- print heel and forefoot interface coupons;
- perform bend, torsion, peel, abrasion, and wet-grip tests.
