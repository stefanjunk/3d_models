# Mechanical library reuse

This folder records which principles from the local FDM mechanical sample
library are reused by the submarine and which candidates were rejected.
The library is digitally validated, but none of the selected samples has a
project-specific physical cycle or underwater test yet.

- Source library: `../../../libraries/fdm-mechanics-library-v1.0.0/`
- Library validation: 120/120 samples passed digital mesh validation.
- Product status: `prototype`; not `qualified-local`.
- Adopted references: samples 002 and 078.
- Rejected for this envelope: samples 109 and 105-108.

Read `selected-source.md`, `parameters.json` and
`physical-test-plan.md` before changing a mechanical interface.
