## Final prompt set

All images used the built-in generation path. The following briefs record the final creative intent; targeted correction passes removed unsupported license, availability, marketplace, multi-format, team and printer-brand language.

### Midnight Forge homepage

```text
Use case: ui-mockup
Asset type: high-fidelity desktop ecommerce homepage, full-page screenshot
Create an original metriCreate homepage that preserves the maintenance-friendly section rhythm of the metriMade reference: utility strip, search-first sticky header, categories, catalog, configurator Studio, process, confidence strip and footer. Reframe it for hobbyists, makers, tinkerers and futurists who primarily buy exact, versioned 3D model files.
Visual thesis: technical studio plus archival catalog. Show an original modular model transitioning from teal wireframe/control points to a solid dark printed result.
Palette: anthracite, midnight #112431, petrol #0D4D53, teal #08777D, aqua #7FD5D3 and controlled signal orange for the single primary action.
Keep practical ecommerce hierarchy and accessible contrast. Use a provisional metriCreate wordmark only. No ratings, testimonials, fake trust marks, marketplace, lifetime-license, security or unsupported performance claims. No printer/nozzle/gear clichés, weapons, purple glow or copied metriMade assets.
```

### Teal Blueprint homepage

```text
Use case: ui-mockup
Asset type: high-fidelity desktop ecommerce homepage, full-page screenshot
Create an original metriCreate homepage with the shared metriMade route/section architecture, but a stronger blueprint and maker-catalog interpretation. The hero shows one original component in three states: parametric control cage, clean CAD surface and printed result. Cards expose revision, a single approved-format concept, printer envelope and configurable state.
Palette: midnight #112431, petrol #0D4D53, teal #08777D, aqua #7FD5D3, cool mist and anthracite; orange appears only as a tiny active/CTA signal.
No Community, creator marketplace, public upload, fake counts, prices, ratings, license-duration claims or unsupported product claims. Use only a provisional metriCreate wordmark.
```

### Carbon Pulse homepage

```text
Use case: ui-mockup
Asset type: high-fidelity desktop ecommerce homepage, full-page screenshot
Create an original metriCreate homepage using the same maintainable information sequence as metriMade, but express it as a neo-brutal technical studio and archival model catalog. Use hard inset frames, an offset CAD hero, condensed headings and a restrained diagonal signal motif.
Palette: carbon, anthracite, midnight, warm gray, burnt signal orange for actions/section markers and teal/aqua only for valid/configurable states.
Mark the catalog visibly as a concept with no live products. Show one 3MF concept format per example. No marketplace, public uploads, reviews, prices, license claims, security claims, purple, gaming or copied product assets.
```

### Midnight Forge Studio

```text
Use case: ui-mockup
Asset type: high-fidelity desktop configurator workspace
Create a metriCreate Studio interior screen in the Midnight Forge visual system. Use a shared storefront header, then a three-column workspace: exact model/revision and file metadata; a large wireframe/solid 3D viewport with dimensions; validated parameter controls and status. The download remains disabled until review.
Add a small collapsible “Assistent (Vorschau)” that explains measurements and parameters but cannot invent inputs, widen ranges or bypass validation.
Use one 3MF format, a generic 220 × 220 × 250 mm FDM profile and visible concept-only status. No price, live-product, team, third-party printer-brand, marketplace, lifetime-license or security claim.
```
