## What this document is for

A trademark search or application must say which goods and services the name covers. The same word can coexist in unrelated sectors, while a similar earlier mark in the same or related goods/services can be a conflict. This scope therefore describes the actual MVP and later options before any Nice-class wording is selected.

It is not necessary to register product names when the catalog uses descriptive titles plus stable IDs. The core decisions concern `metriMade`, `metriCreate`, their selected logos and optionally `JuSt Innovation`.

## Candidate Nice-class issue list

This is a search checklist, not ready-to-file wording. Validate the current terms in DPMA/EUIPO classification tools before an application.

| Candidate class | Why it may apply | Current decision |
|---|---|---|
| Class 9 | Downloadable digital/CAD/3D-model files and possibly downloadable configuration software | Core `metriCreate` search scope; exact accepted terms required |
| Class 35 | Online retail services relating to downloadable model files and specified printed goods | Relevant to both storefronts; list the retailed goods per brand precisely |
| Class 42 | Product/industrial/CAD design, parameterization, configuration software or SaaS | Core `metriCreate` search scope |
| Class 40 | Custom manufacture and 3D-printing services for others | Later `metriCreate` print-order scope; include only when realistically offered/reserved |
| Product-specific classes | Physical organizers, containers, bookends or decor are classified by the exact goods/material/function | Do not guess now; add only from released printed SKUs |

Paying extra classes for hypothetical activities increases scope and maintenance without fixing an unclear business model. Conversely, filing only a logo may protect that particular visual form more narrowly than a cleared word mark. The filing owner should decide separately for the word marks and selected logos.
