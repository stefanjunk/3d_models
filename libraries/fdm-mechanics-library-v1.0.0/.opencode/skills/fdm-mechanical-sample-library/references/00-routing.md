# Routing

Use this library for mechanism primitives and tolerance probes. Route load cases, fasteners, material allowables, bearings, motors, and safety factors to `functional-3d-design`. Route smooth product shells to `parametric-freeform-surfacing`. Route protected AI/scan meshes to `organic-mesh-functionalization`.

The library sample may define the kinematic interface, but the product project owns its load path, enclosure, hardpoints, test plan, and release decision.
