# Selection matrix

| Need | Preferred family | Alternative | Main risk |
|---|---|---|---|
| Removable single-axis hinge | offset pin hinge | hook latch pivot | pin wear and axial offset |
| Low-play small-angle pivot | thin flexure | serpentine hinge | fatigue and creep |
| Two-axis angular motion | pinned gimbal | universal joint | horizontal bores and pins |
| Adjustable arbitrary angle | clamp ball joint | snap ball joint | surface friction and retention |
| Permanent plug | keyed plug or press dowel | barb | splitting and insertion force |
| Reusable closure | bayonet or slide bolt | snap latch | wear and accidental release |
| Smooth linear travel | preload slider | dovetail rail | friction and rail warp |
| Compact linear restraint | T/mushroom rail | dovetail rail | undercut accuracy |
| Rotary-to-linear drive | rack/pinion | cam | simplified tooth profile |
| Tactile indexing | detent disk | snap latch | spring creep |
