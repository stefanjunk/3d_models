## Ausschlusskriterien (in allen Berichten eingehalten)

Kein Lebensmittelkontakt, kein Kinderspielzeug, keine Medizinprodukte, keine PSA/Schutzwirkung, keine tragenden Sicherheitsbehauptungen, Bauraum ≤ 450³ mm.
