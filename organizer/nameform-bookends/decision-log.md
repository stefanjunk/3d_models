# Decision log — MM-PER-001 NameForm Bookends

All options resolved per the user's 2026-08-21 blanket pre-approval (pipeline test).
Recommended default chosen for each item; trade-off noted.

| # | Decision | Choice | Rationale / trade-off |
|---|---|---|---|
| D1 | Product selection | NameForm Bookends (MM-PER-001) | Research rank #1 (4.85/5, `market_research/bericht-top20-alltags-organizer-kleine-wohnraeume.md`); core personalization strategy; P0 NOW, no CAD yet (pure design work); low risk class; fits 220×220×250 bed. DrawerFit (MM-ORG-001) already has CAD (correction path, not design); ShelfFit (MM-ORG-002) more commodity-like. |
| D2 | Book mechanics | Layout B: word face to viewer, books lean on full-height rear stop panel bonded to letters | Matches research prompt exactly ("Buchstaben verbinden Boden und Anschlag formschlüssig; Anschlagfläche als Rücken für die Buchreihe"). Keeps name fully visible (books would hide a front-facing word). Panel closed by letters → rigid full-height stop. |
| D3 | Word scope | 1–10 uppercase chars parametric; cap auto-scaled `H = min(180, 192/advance_em)`; assert H ≥ 40 mm | Bed-constrained (220×220×250 decision). Long words auto-shrink; below 40 mm cap the tool refuses (honest tiering) instead of printing a 20 mm bookstop. Trade-off: 5–10 char words become short bookstops (documented). |
| D4 | First fixed revision word | "M" | 2-letter+ words (e.g., "MI") exceed the 192 mm width budget at full height with DejaVu Sans Bold; single "M" fits at full 180 mm cap → maximum book-holding + maximum ballast + cleanest hero image. Later manual variants: "MI", "MAX", "LESEN" at computed tiers. |
| D5 | Construction | 100% infill solid (base + letters + panel), no TPU pad, no purchased parts | Ballast is the function (tip-over SF). TPU pad excluded by MVP "one 3MF, PLA/PETG only". Anti-slip via underside texture + mass. Trade-off: heavy part (~1.3 kg), longer print time — stated in listing. |
| D6 | Base sizing | ~197 × 100 × 20 mm (word width + 24 mm margin, 100 mm depth toward book side as ballast toe) | Resisting moment arm ~62 mm vs. stop contact; passes 2.0 kg / 25 mm offset / SF 1.5 with ~8% margin (exact value from mesh volume in validation). 12 mm base (research) would fail the duty. |
| D7 | Letter depth | 50 mm (start value; script solves minimum passing depth) | Stiffness of the stop face + ballast; deeper = heavier/slower, shallower = SF risk. Final value = smallest passing ≥ 50 mm with SF ≥ 1.5. |
| D8 | Stop panel | 4 mm thick, full cap height, full base width, 2 mm overlap into letters | Research says 3 mm; +1 mm margin for local gap deflection (checked ≤ 1 mm at 2 N). Full height = stop for full-height books. |
| D9 | Material / profile | Matte PLA, 0.4 mm nozzle, 0.2 mm layer, upright, no supports | Appearance-led product (research: PLA matt, Sichtqualität); 0.2 mm ≤ 75% of 0.4 nozzle ✓; upright print = no supports (letters/panel are vertical extrusions). PETG allowed alternative. |
| D10 | Tool route | OpenSCAD source + Python (fontTools metrics, trimesh validation, 3MF export) | Skill routing: OpenSCAD for text/relief/compact params/CLI. Trimesh already available; OpenSCAD installed. STEP N/A (no functional interfaces; 3MF is business release format). |
| D11 | Font | DejaVu Sans Bold, `/usr/share/fonts/truetype/DejaVuSans-Bold.ttf` (SIL OFL 1.1) | Sturdy wide glyphs (good for strokes ≥ 4 mm and ballast mass); OFL license → clean G1 commercial scope. Recorded in source register. |
| D12 | Watermark | JSI-WM-001-R1 standard profile, recessed 0.4 mm, base underside (largest bed-facing safe region), last solid change | Skill + manifest requirements; base underside 197×100 mm, host wall 20 mm ≫ 1.2 mm min. |
| D13 | Gates | All gates pre-approved by user 2026-08-21 (pipeline test) | User instruction. Traceability: approver recorded as user's blanket pre-approval; states kept honest in `design-spec.yaml` as each artifact is created. |
| D14 | Physical tests | Not executed in this session (no printer run); recorded as open P3 gate | Skill stop rule: no autonomous printer start. Test plan delivered (test-plan.yaml TP-01…TP-06) for the operator to run on Kobra 3 Max. |
| D15 | 0.1.0 defect diagnosis | rev 0.1.0 mesh is MISSING the letter "M" (STL = slab + panel only, 903.99 cm³); master and final byte-identical (no watermark cut); raster min-feature artifact 1.0 mm; pair 3MF span 452 mm violates the 220 mm bed | Root cause: unquoted `openscad -D WORD=M` → `text()` renders empty (exit 0); invalid `halign="Center"`/`valign="Baseline"`. Secondary: master/final never differentiated. 0.1.0 judged DEFECTIVE; source archived; exports regenerated. |
| D16 | 0.2.0 fix route | Port the whole design to CadQuery (B-Rep source of truth) and fix it there | CadQuery gives deterministic B-Rep text (no raster artifacts), correct alignment, clean STL/STEP, and exact watermark booleans. OpenSCAD source kept in `source/archive` as the defective record. |
| D17 | Watermark sizing + orientation | Apply the selector's uniform scale 1.6875 (standard 32×10 → 54×16.875 envelope), recess 0.40 mm, X-mirror the asset and re-center so it reads normally from the finished underside | The 0.1.0 mark was undersized (29.3×9.6). The selector never shrinks — it scales up for process safety. Orientation verified by camera math (finished-underside image frame = (−part_x, +part_y)); X-mirror = normal reading. |
| D18 | Release 3MF | One 3MF holds ONE marked part; the pair = two sequential prints of the same file | A 216×152 part cannot print in-pair on a 220 bed (span 452 mm). Single part per file is the honest, bed-fitting release format. |
| D19 | Gate recording (0.2.0) | Record requirements, concept, and watermark as approved at 0.2.0 under the 2026-08-21 blanket pre-approval; watermark `geometry_revision` = final STL SHA-256 `ff0fb59b…` | 0.2.0 is a defect-fix implementation of the already-approved 0.1.0 design (no change of design intent). The user's blanket pre-approval ("uebergehen alle Freigaben und Approvals und fuehre es zu Ende") covers all three gates. |
| D20 | 0.3.0 architecture reset | Replace the two-identical-part front/back stop with a true mirrored left/right pair: inner side blades, inward under-book feet, and outside front text wings | User instruction 2026-08-26: "fix it, follow your recommendations and go on" after the audit found the concept/load-direction mismatch. Functional geometry is decoupled from name length. |
| D21 | 0.3.0 personalization | Default `STEFAN -> STE | FAN`; support automatic width-balanced splits, explicit independent halves, initials, and same-name-on-both modes with shared scale/baseline | The 0.2.0 pipeline was hard-coded to M and failed 11/26 direct single-letter probes. The new pipeline must fail closed on missing glyphs and sweep the supported set. |
| D22 | 0.3.0 mass strategy | Replace the 1.841 kg solid-PLA ballast part with thin continuous plates, local ribs/gussets, and book-loaded inward feet | The previous pair required about 3.68 kg PLA and its 3MF did not enforce 100% infill. The new load path uses the books' weight and reserves material for continuous structural paths. |
| D23 | 0.3.0 concept | New concept sheet generated at `concept/nameform-bookends-v0.3.0-concept.png`; approval pending | It shows the approved requirements but remains non-dimensional and cannot authorize production CAD until explicitly approved. |
| D24 | 0.3.0 concept approval | Approved by Stefan on 2026-08-26 ("freigegeben") | Production CAD may now begin against specification revision 0.3.0. |
| D25 | Under-book foot refinement | Use a 2.0 mm foot with a 15 mm taper to a 0.6 mm inner toe; keep structural blade/wing plates at 3.2 mm | Avoids lifting the outer books by the full structural-plate thickness, remains support-free, and still leaves 1.6 mm wall after the 0.4 mm underside mark. |
| D26 | Personalized build interface | Add a fail-closed `customize_v030.py` entry point for automatic split, explicit pair, and whole-name-on-both modes; marked STEP/STL/3MF is the default | Turns the font/name logic into a repeatable user workflow.
