# Interface coupon 0.3.0

This off-product build qualifies the concealed permanent seam connector and the
local hanger/standoff slide-snap socket. It contains loose, production-oriented
parts at **0.15, 0.25, 0.35 and 0.45 mm clearance per side**. The layout legend,
from the lowest Y row upward, is 0.15, 0.25, 0.35 and 0.45 mm. Within every row,
the parts run from left to right as left seam receiver, right seam receiver,
connector, socket receiver and test anchor.

Print the coupon with the exact production filament, 0.4 mm nozzle, 0.20 mm
process and part orientation. Select the smallest variant that fully inserts
once without crack or visible whitening and seats both retaining features.
Record the insertion observation and a destructive pull observation. The
coupon does not establish a universal pull force, fatigue life or wall-load
rating.

The nominal digital product candidate uses 0.25 mm per side only provisionally.
Do not promote the artwork to print-candidate status until a physical winner has
been recorded. Reprint this coupon whenever filament product/batch, nozzle,
orientation or slicer profile changes.
