# Furniture cabinetry

Free-standing built furniture whose manufacturing route is **timber panel
cutting and hardware assembly**, not FDM printing. Each child directory is a
complete SKU package: parametric source, cut list, drill plan, bill of
materials, purchased-hardware register, build manual and evidence.

This family exists because the artifact set differs from every printed family:
there is no nozzle, no slicer profile and no mesh. The controlling documents are
the cut list (`exports/cut-list.csv`), the drill plan (`exports/drill-plan.csv`)
and the measured host niche.

`furniture-systems` remains the family for inserts and accessories that adapt an
existing system-furniture host (IKEA and similar). Products here are the
furniture itself.
