# ShelfFit Mini Bins — MM-ORG-002

This project contains the controlled `v0.1.0` reference model for two identical open-top shelf bins. The current files are DRAFT engineering artifacts; they are not a commercial release and do not establish physical shelf fit or a load rating.

Reference layout: 420 × 210 × 150 mm shelf interior, two 208.5 × 208 × 148 mm bodies, one manufacturing file printed twice. The top rim expands the maximum print envelope to 210 × 209.5 × 148 mm and still fits the declared 220 × 220 × 250 mm common-printer contract.

Build and validation commands will be recorded with the generated source. Do not upload or start a print automatically.
