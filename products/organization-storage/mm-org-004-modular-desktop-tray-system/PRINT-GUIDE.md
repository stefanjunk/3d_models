# DRAFT print guide

- Material assumption: dry indoor PLA prototype; PETG requires a fresh clearance coupon.
- Nozzle / layer starting point: 0.4 mm / 0.20 mm, 0.45 mm nominal line width.
- Trays: bottom down, no generated supports; use at least three wall paths and four bottom layers as a starting point.
- Connector: largest flat face down; print two for the three-tray reference layout.
- First print: `exports/coupons/DRAFT-MM-ORG-004-interface-coupon-0.1.0-draft.1.stl`.
- Inspect the short receiver roof bridge before attempting a full tray.

This is provisional process guidance, not a validated slicer profile. Do not scale interface parts independently.
