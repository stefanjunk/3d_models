# MM-ORG-006 — Charging-cable Docking Bar

Parametric passive docking bar with a rigid PETG frame and replaceable TPU cable inserts. The default set provides four sockets and four insert sizes so charging/data cable ends remain accessible instead of falling behind furniture.

This implements research idea `SKU-004` as a DRAFT digital engineering candidate. It does not charge, electrically connect, insulate or provide certified strain relief.
