# Optimization plan and comparison

The A baseline is a full 156 × 40 × 14 mm rounded body with the same four insert pockets. The selected B geometry retains a continuous 3 mm base skin, front/rear edge beams and four local receiver cells while removing bulk that has no interface or stability role.

| Candidate | Lever | Result |
|---|---|---|
| A | full-body bar, same pockets and 0.4 mm process | frozen analytic baseline |
| B | thin base + edge beams + local cells | selected; about 59.7% lower bar CAD volume |
| C | B plus 0.6 mm nozzle hypothesis | not selected without exact PETG/TPU slicing |

The 59.7% figure is analytic bar volume only, not deposited mass or print time. The PETG base footprint, socket floors/datums and TPU interface remain protected. Stability and one-handed use require the unchanged physical assembly.
