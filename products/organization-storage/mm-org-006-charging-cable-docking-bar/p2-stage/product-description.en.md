# Charging-cable Docking Bar

Parametric passive docking bar with a rigid PETG frame and replaceable TPU cable inserts. The default set provides four sockets and four insert sizes so charging/data cable ends remain accessible instead of falling behind furniture.

## P2 digital-candidate contents

This English development description applies to `MM-ORG-006` revision `0.1.0-draft.1`.
The complete candidate 3MF contains 5 declared print object(s):
insert_3p5, insert_5p0, bar, insert_7p0, insert_9p0. The included project preserves the selected build orientation and
the recorded support decision for the candidate.

## Development boundary

This is a digital P2 candidate, not a photograph or a physically qualified or
commercially released product. Fit, finish, strength, safety, rights clearance,
material behaviour and storefront claims remain governed by their separate
evidence and approval gates.
