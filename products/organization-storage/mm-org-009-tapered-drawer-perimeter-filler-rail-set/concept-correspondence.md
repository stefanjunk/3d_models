# Concept correspondence

| Visible concept feature | Requirement mapping |
|---|---|
| Mirrored left/right rails | Close both perimeter gaps while preserving independent measurements. |
| Different front/rear widths | `front_gap_mm` and `rear_gap_mm` taper parameters. |
| Straight organizer-side edges | Stable straight datum with explicit loose clearance. |
| Rounded outer/top edges | Pinch and finish-contact risk reduction. |
| Two lift scallops per long rail | Tool-free removal without an interference fit. |
| Ribbed hidden underside | Material reduction while protecting top and interface skins. |
| Separate gauge | Physical calibration before spending a full-rail print. |
