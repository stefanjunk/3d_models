# Deferred physical test plan

| ID | Test | Pass condition |
|---|---|---|
| TP-01 | Coupon insertion | Plate inserts by hand, stays captured and is removable without tool damage |
| TP-02 | Engraving | `M8` and production name are readable with no closed or missing pixels |
| TP-03 | Plate cycles | 250 insertion/removal cycles without cracked lips or unintended release |
| TP-04 | Phone envelope | Representative devices/cases up to the declared 12 mm thickness remain seated during normal desk taps |
| TP-05 | Tall-item loading | Representative pens, markers, ruler and scissors do not tip the loaded caddy in intended use |
| TP-06 | Asymmetric load | Full right well plus empty left wells does not cause static tipping |
| TP-07 | Edge/desk contact | No injurious burrs; base and optional feet do not visibly mark three representative desk finishes |
| TP-08 | Clean/use cycle | 30 days of dry indoor use produces no cracking, delamination or trapped debris that cannot be removed |

Record machine, material brand/type/color/batch, nozzle, orientation, slicer/profile, environment and measurement method. These tests are intentionally not run in this phase.
