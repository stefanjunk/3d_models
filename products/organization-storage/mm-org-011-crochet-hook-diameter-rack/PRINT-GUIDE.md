# Draft print guide

- Material assumption: PLA, dry indoor use.
- Nozzle/layer: 0.4 mm / 0.20 mm.
- Rack orientation: continuous base flat on the bed; do not rotate onto a side.
- Card orientation: broad face flat, engraved labels upward.
- Generated supports: none; every shelf uses a continuous base-connected rising underside.
- First print: measurement card, then replace the 15 default profiles with actual measurements and rebuild.
- Do not start from this repository automatically. Confirm printer, filament, first layer and unchanged revision locally.
