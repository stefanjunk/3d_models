# MM-ORG-011 Crochet-hook diameter rack

Parametric three-tier rack for 15 measured crochet hooks. Each shaft enters laterally through an individually sized open slot, so the hook head and ergonomic handle never need to pass through a uniform closed hole. A flat gauge card measures the shaft and handle envelope before customising `config/model-parameters.json`.

Build with `python cad/build.py`; run parameter tests with `python -m pytest -q tests/test_parameters.py`.

All outputs are `DRAFT-...-0.1.0-draft.1`. Physical hook fit, abrasion, stability, watermark approval and commercial release remain deliberately open.
