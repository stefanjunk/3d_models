# Draft print guide

- PLA, 0.4 mm nozzle, 0.20 mm layer height.
- Tray and coupon print with their continuous base on the bed.
- Generated supports: none; all ramps grow continuously from the base.
- First print the coupon and trial one lead case, one eraser pack and one clip box.
- Replace generic package envelopes with actual measurements before a custom full-tray print.
- No automated printer upload/start is authorized.
