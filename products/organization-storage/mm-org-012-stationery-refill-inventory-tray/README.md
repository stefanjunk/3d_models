# MM-ORG-012 Stationery-refill inventory tray

Parametric 180 x 140 x 45 mm tray for packaged mechanical-pencil leads, ink refills, erasers, clips and cartridges. Five rear packet lanes and three front pockets use rising floors, thumb notches and permanent geometric labels. A three-cell coupon is the intended first print.

Build: `python cad/build.py`. Tests: `python -m pytest -q tests/test_parameters.py`.

All outputs remain DRAFT until actual package retrieval, drawer clearance, watermark and release gates pass.
