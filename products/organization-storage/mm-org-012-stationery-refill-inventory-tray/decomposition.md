# Decomposition

- **Inventory tray:** one analytic solid containing base, walls, dividers, ramps, thumb notches and permanent labels.
- **Retrieval coupon:** one smaller analytic solid with three ramped cells for lead, eraser and clip package trials.
- **Configuration:** JSON owns tray envelope, eight package profiles, labels, clearances and coupon dimensions.
- **Manufacturing package:** separate tray/coupon STL objects plus one two-object millimetre 3MF.
- **Deferred evidence:** actual package measurements, retrieval cycles, label appearance and drawer clearance.
