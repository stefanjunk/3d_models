# MM-ORG-013 Photo/postcard archive drawer divider

Parametric slotted drawer cassette for sleeved photographs and postcards stored on edge. The default frame accepts media up to 180 mm long, provides ten divider locations and uses six individually labelled, flat-print divider plates. Three full-size U-gauges cover 10 x 15 cm, DIN A6 and 13 x 18 cm.

Build with `python cad/build.py`; run parameter tests with `python -m pytest -q tests/test_parameters.py`. The three exact-profile 3MF build sets and all ten meshes pass deterministic digital checks; see `final-model-result-report.md`.

All outputs remain `DRAFT`. This is an organizer around photo-safe primary sleeves, not an archival enclosure; paper snagging, tab visibility, drawer closure, material compatibility, watermark and release remain open.
