# Product decomposition

1. **Archive frame** — source-controlled base, perimeter, guide wall and aligned receiver slots.
2. **Labelled divider family** — one profile driven by thickness, heights, label text and installed slot position; manufacturing orientation is broad-face-down.
3. **Format gauge family** — three U-shaped, open-entry full-size media envelopes driven directly from the format table.
4. **Assembly transform** — inserts the vertical divider plates into selected frame slots without changing manufacturing meshes.
5. **Evidence layer** — parameter, B-Rep, mesh, 3MF, interface, slicer and deferred physical checks.

Protected interfaces: continuous base, slot web, media clearance, guide-wall alignment, divider insertion thickness, snag-relief shoulders and label-pixel minimum.
