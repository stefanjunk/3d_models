# Draft print guide

- Print the coupon first with the same material, orientation and profile intended for the dock.
- Dock and coupon print flat on their lattice bases; no generated support is intended.
- Reference profile: Anycubic Kobra 3 Max, 0.4 mm nozzle, 0.20 mm Standard, Anycubic PLA.
- Insert only blunt card edges. Do not store needles in the slots.
- Trial actual loaded cards at 0.6, 2.0 and 3.0 mm classes, inspect fiber contact and verify one-handed retrieval before the full print.
- The passed digital slice contains 60 layers and an estimated 14,000 seconds; re-slice after changing geometry, package placement, machine, process or material profile.
- For the physical gate, measure the loaded insertion edge rather than the nominal unloaded card body. Reject any class that creases, marks, snags fibers or requires unsafe retrieval force.
- Load all thirty positions, confirm labels remain readable, check desk slip/tip behavior and cycle the worst-fitting class 500 times before treating the draft as qualified.
- Inspect the destination slicer's layer preview before printing. No printer upload or print-start action is part of this project.
