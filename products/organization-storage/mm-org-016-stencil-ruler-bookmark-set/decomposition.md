# Decomposition and ownership

- JSON source owns plate envelope, grid cadences, feature rules, icon-cell positions, coupon sweep, printer and mesh budgets.
- CadQuery source owns all solids, all project-original icon paths, registration layout, STEP/STL export, deterministic 3MF packaging and machine-readable reports.
- Three production plates are independent one-piece manufacturing components with no mating interface.
- The feature coupon is an independent process witness and must never be substituted for physical paper/pen validation.
- The user owns paper, pens, notebook format, slicer overrides and all physical observations.
- Physical validation owns stiffness, edge roughness, page marking, ink bleed/smear, traceability and 250-use durability.

No purchased components, third-party meshes, fonts, trademarks or external vector assets enter the geometry.
