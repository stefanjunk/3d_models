# Stencil-ruler bookmark set

Keep 4 mm, 5 mm and original signal-mark layout tools inside an A5 or A6 journal without a paper-pinching clip.

## P2 digital-candidate contents

This English development description applies to `MM-ORG-016` revision `0.1.0-draft.1`.
The complete candidate 3MF contains 4 declared print object(s):
layout-5mm, layout-4mm, signal-12, minimum-feature-coupon. The included project preserves the selected build orientation and
the recorded support decision for the candidate.

commercially released product. Fit, finish, strength, safety, rights clearance,
