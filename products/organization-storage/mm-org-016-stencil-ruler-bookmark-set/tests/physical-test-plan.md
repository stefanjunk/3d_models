# Deferred physical test plan

1. Print the feature coupon in the exact intended material/profile and measure all five slots and holes with calibrated calipers.
2. Reject any production minimum that closes, strings, tears the paper, catches a pen tip or cannot be cleaned without changing its geometry.
3. Print all three plates broad face down; inspect outer corners, both faces and every aperture for burrs or sharp ridges.
4. On sacrificial versions of every intended paper, trace all layout features and twelve signals with each intended pen; record bleed-under, smear, skip and tip contact.
5. Verify 4 mm and 5 mm registration over the full 120 mm run against a trusted scale and the notebook's actual grid.
6. Store each plate inside A5 and A6 notebooks for seven days under normal carrying load; inspect page impressions, curl and permanent set.
7. Run 250 trace/store/retrieve cycles per production plate and repeat aperture, edge and flatness inspection.
8. Reject child, cutting, fountain-pen, precision-instrument, no-mark, no-smear or universal-paper claims without separate evidence.
