# Optimization plan

The reference baseline is a solid block equal to each rack's outer retaining envelope. The candidate keeps only a three-millimetre base, narrow dividers, a low front label rail and an inclined rear rail.

Protected dimensions take precedence over material reduction. The initial target is at least 65% CAD-volume reduction versus the two solid rack envelopes. Analytic tessellation must stay below 60,000 triangles and 8 MiB per mesh; decimation is rejected if those budgets already pass because it could move interface surfaces.

The exact Anycubic profile is used for print-time and material evidence. G-code is temporary and must not be retained, uploaded or sent to a printer.
