# Decision log

## 2026-08-28 — select measured closed-case storage

Paid multi-glasses boxes validate separated, visible eyewear storage, but fixed bare-glasses cells conflict with user reports of oversized items not fitting. Selected a brand-neutral corral for each user's existing closed cases, preserving the case as the only optical-protection component.

## 2026-08-28 — stand cases on the short end

Case length is vertical, maximum thickness owns lane width and case depth owns base depth. This matches the portfolio variables and exposes each case face while keeping the printed organizer under 220 × 160 × 140 mm.

## 2026-08-28 — bias cases rearward without hardware

The floor falls 3 degrees toward a 54 mm rear wall. Full 82 mm dividers control lateral tip and support soft cases; a 14 mm front stop retains the foot. These are digital design features only until empty/inert case tests pass.

## 2026-08-28 — stop at digital print candidate

Exact-profile slicing is complete. Hard/semi-rigid/soft fit, static tip, adjacent retrieval, 100 cycles, shelf sliding and label adhesion remain user-owned. No G-code was retained or sent to a printer.
