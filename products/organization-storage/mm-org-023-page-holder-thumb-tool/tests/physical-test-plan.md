# Physical test plan — deferred

1. Print the sizing guide and measure all major/minor openings with calibrated calipers. Record the print orientation and measurement method.
2. Insert the thumb only to the intended working depth. Select the smallest opening with no compression, catching or forced removal. Stop immediately on pain, numbness or skin color change.
3. Print the selected full holder. Complete a conservative 10-minute unloaded comfort sample, checking pressure points and rotation; this is not a medical assessment.
4. Test a small paperback, large paperback and hardcover for initial placement, static page holding, deliberate page turning and removal. Do not force a stiff binding flat.
5. Inspect representative inexpensive pages after 25 placements for creasing, dents, abrasion, ink transfer or edge snagging. No paper-protection claim is permitted even after passing.
6. Complete 100 insertion/removal and book-placement cycles. Reject cracking, roughness, permanent deformation or loosened page-pad edges.
7. Repeat with PETG only as a separately recorded material/process scope if PLA comfort or durability is inadequate.

Pass/fail authority remains with the user operating the printer and conducting the comfort check.
