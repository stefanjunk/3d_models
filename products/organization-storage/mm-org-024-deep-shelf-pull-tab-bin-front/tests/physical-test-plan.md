# Physical test plan — deferred

1. Print and measure the three gauge gaps; record printer, PETG manufacturer/product/color/batch, conditioning, nozzle, orientation, slicer profile and caliper method.
2. Select the smallest non-forced gap on a flat, non-tapered host zone. Inspect immediately and after 24 hours for whitening, creep, denting, gloss change or permanent marking.
3. Print one selected clip plus the key-slot coupon. Complete 50 install/lock/remove cycles; reject cracks, looseness, head damage or unintended side release.
4. Print the face and a second identical clip. Confirm both clips seat evenly and the face does not cover a host opening, latch or existing grip that must remain accessible.
5. With 0.75 kg distributed test contents on the intended dry shelf, perform 500 controlled horizontal pull/replace cycles. Do not lift the bin.
6. Reject progressive slip, clip whitening, cracks, key movement, host damage, sharpness or a pull force that requires jerking.
7. Insert a 76.2 × 20 mm paper label and complete 100 label changes plus normal pulls; reject unintended release or snagging.

The 0.75 kg value is only a test target until this unchanged revision passes. Pass/fail authority remains with the user operating the printer.
