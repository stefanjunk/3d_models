# Print guide — digital candidate

Use the included fit key and slot gauge before the full organizer. The reference digital evidence uses Anycubic PETG, Kobra 3 Max, 0.4 mm nozzle, 0.20 mm Standard, no supports.

- Base: print rails on the bed in the exported orientation.
- Divider ×7: print broad face down.
- Slot gauge and fit key: print broad face down together.
- Do not scale individual parts; scaling changes the protected fit.
- Keep elephant-foot compensation consistent between coupon and base.
- Deburr only loose stringing; do not file slots to manufacture a result that the parameter set does not describe.

Start with the coupon protocol in `tests/physical-test-plan.md`. If 2.9 mm is not the chosen slot, edit the parameter and regenerate; do not print the old base.

Use only for closed, dry palettes on a stable indoor countertop. Keep away from high-heat hair tools. This candidate has no universal-fit, hygiene, scratch-resistance, stability, or load claim until physical tests pass.
