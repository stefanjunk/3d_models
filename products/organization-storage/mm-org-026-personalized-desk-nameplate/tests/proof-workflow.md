# Privacy-minimizing proof workflow

Collect only name, title, requested colors, and optional desk footprint. Normalize locally with `tools/live_text_preview.py`; return the SVG plus normalized strings and `font_id` for approval. Store the buyer-approved proof with the order evidence, not in the reusable CAD source, font library, learning store, screenshots, or public test fixtures.

Reject requests that impersonate credentials, protected marks, public authorities, employers, or affiliations without separate review. Do not infer title legitimacy. The default `ALEX MORGAN / DESIGN STUDIO` is synthetic demonstration content.
