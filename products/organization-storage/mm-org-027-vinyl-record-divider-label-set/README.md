# MM-ORG-027 ShelfCue

Fully parametric draft digital candidate for portfolio SKU-024: a CSV-personalized, front-readable vinyl shelf index set that fits the retained 235 × 105 × 5 mm single-part envelope.

Run `python tools/import_labels.py`, then `python cad/build.py`. The selected batch contains six identical smooth carriers, six unique engraved caps, a cap-slot gauge and a carrier fit key. Edit `config/labels.csv` and the JSON parameters, then regenerate all downstream artifacts and evidence.

This is a dry-indoor index, not a full record divider, anti-lean support or archival/preservation product. Use only between separately qualified protective outer sleeves. Physical and commercial validation remain open.
