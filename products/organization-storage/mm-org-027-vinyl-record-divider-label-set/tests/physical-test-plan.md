# Deferred physical test plan

1. Print gauge and fit key first. Select the slot that assembles by hand, retains the key under a gentle downward shake and removes without whitening or cracking.
2. Print one full smooth carrier and measure corner lift on a flat reference after 24 hours; pass at no more than 0.8 mm.
3. Deburr only if necessary, then run a lint-free cloth and sacrificial protected sleeve across every carrier edge; reject snagging or visible scoring.
4. Assemble one cap and carrier for 250 attach/remove cycles; reject cracks, permanent looseness or slot growth that causes unintended detachment.
5. Install six indices among sacrificial protected sleeves in the actual shelf/box. Confirm labels are readable, tab offsets prevent unacceptable overlap, and records retrieve without binding.
6. Run 500 representative record retrieval/replacement cycles and inspect sleeves, spines, caps and carrier flatness.

Record printer, filament product/color/batch/drying, nozzle, profile hash, build surface, ambient conditions, measurements and failure modes.
