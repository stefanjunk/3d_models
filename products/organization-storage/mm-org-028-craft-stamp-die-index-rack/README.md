# MM-ORG-028 IndexDock 15

Fully parametric draft digital candidate for portfolio SKU-158: a fifteen-lane craft stamp/die index rack for filled protective envelopes or cases in the retained 220 × 180 × 200 mm single-part envelope.

Run `python tools/import_labels.py`, then `python cad/build.py`. The selected system contains one three-rail rack, four CSV-driven high index frames, a lane-gap gauge and an exact divider-foot key. Two 3MF build sets keep the rack kit and four tall flat-printed dividers inside the Kobra 3 Max bed.

This rack does not hold loose dies, blades or unprotected stamps. The default format supports filled envelopes/cases up to 145 × 195 × 10 mm; wider 6×7, 9.5×7 and 7×10 products require a separately regenerated and validated configuration. Physical and commercial validation remain open.
