# MM-ORG-029 · CraftOrbit 4

Fully parametric draft digital print candidate for portfolio SKU-160. Four repeated two-compartment caddies dock around a shared center cup and use CSV-generated replaceable nameplates.

Start with `config/model-parameters.json` and `config/names.csv`, then run `tools/import_names.py`, `tools/live_batch_preview.py` and `cad/build.py`. The selected manufacturing package is `exports/3mf/DRAFT-MM-ORG-029-four-caddy-system-0.1.0-draft.1.3mf`.

Digital status: CAD, mesh, 3MF and exact Kobra 3 Max slicer candidate. Physical fit/function and commercial release are deferred.
