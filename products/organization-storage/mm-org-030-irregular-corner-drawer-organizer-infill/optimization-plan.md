# Optimization plan

Compare unchanged 3 mm-shell CAD at 0.20 and 0.28 mm. Both must be warning-free and single-tool; select the faster Pareto option only if estimated extrusion growth stays within 12%. Generate a 2.4 mm round-tray variant but reject it until load, flex, drop and drawer-cycle tests exist. Compare selected shells with three solid rectangular envelopes only as a geometric proxy.
