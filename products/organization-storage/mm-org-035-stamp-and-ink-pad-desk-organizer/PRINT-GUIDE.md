# Print guide

1. Measure the closed ink-pad case; do not rely only on a brand label.
2. Print the two-mouth fit coupon and test insertion, label visibility, removal, and front-tab retention.
3. Choose only the module whose declared case envelope contains the measured case.
4. Preview the exact G-code for layer, seam, support, and bed placement; supports remain disabled.
5. Print the unchanged selected module or both-module plate in PETG, profile-side down as supplied.
6. Line the top stamp-rest tray with replaceable scrap paper before placing an inked stamp. The printed tray is not an ink reservoir or chemically qualified cleaning surface.
7. Complete `tests/physical-test-plan.md` before compatibility or sale claims.

Supplied G-code is local validation evidence, not authorization to upload or start a printer.
