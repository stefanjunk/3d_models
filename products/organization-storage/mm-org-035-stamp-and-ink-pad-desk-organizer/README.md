# MM-ORG-035 InkNest Duo

Controlled parametric implementation of portfolio research item `SKU-047`.

InkNest Duo is a two-module PETG desk organizer for closed ink-pad cases and an actively used stamp resting on a scrap-paper-lined top tray. The DRAFT package pilots two case envelopes: 78 x 78 x 21 mm and 100 x 69 x 21 mm.

Start with `PRINT-GUIDE.md`. Physical case fit, stability, ink/cleaning compatibility, cycles, appearance, and commercial release remain human-controlled.

Current digital candidate: `0.1.0-draft.2`. The separate fit-coupon and complete two-cassette 3MF plates have exact, warning-free Anycubic Slicer Next 1.3.9.4 evidence for the Kobra 3 Max 0.4 mm / 0.20 mm / Anycubic PETG profile set. Draft.1 remains preserved as rejected slicer-warning evidence.
