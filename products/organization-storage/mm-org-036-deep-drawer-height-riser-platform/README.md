# MM-ORG-036 LiftDeck 50

Controlled parametric implementation of portfolio research item `SKU-104`.

LiftDeck 50 raises an existing small organizer tray inside a deep drawer while leaving an open, hidden cavity below. The 180 x 140 x 50 mm pilot is a one-piece PLA lattice platform printed top-face-down without supports.

Start with `PRINT-GUIDE.md`. The supplied full platform is a conservative digital print candidate with four corner posts plus one center post. The corner-post and rib-support coupons are both retained because 2 kg / 30-day creep testing, drawer fit, tray stability, heat exposure, appearance, and commercial release remain human-controlled.

Revision `0.1.0-draft.2` adds the required unscaled R2 Full metriMade identity mark on a dedicated underside land. The final marked platform is a one-component watertight digital print candidate; exact Anycubic Slicer Next jobs are warning-free with support disabled. The open grid saves 35.08% CAD volume against the marked solid-deck proxy. Physical load/creep, fit, final visual preview, and mark legibility remain human gates.
