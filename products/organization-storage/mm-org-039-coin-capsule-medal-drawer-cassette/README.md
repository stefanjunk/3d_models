# MM-ORG-039 CollectorGrid 6

Controlled parametric implementation of portfolio research item `SKU-109`.

CollectorGrid 6 is a `214 x 144 x 16 mm` six-cell drawer cassette for protective coin or medal capsules. Each `68.13 x 68.4 mm` cell directly accepts a measured `67 x 67 mm` large square capsule target or a loose, removable adapter. Two supplied adapters target `50 x 50 x 6.25 mm` square capsules and `46 mm` outer-diameter round capsules. Each adapter also includes a recessed `34 x 7.5 mm` paper-label bay.

Start with `PRINT-GUIDE.md` and print the gauge package before either complete kit. Compatibility is defined only by measured outer dimensions; brand names, nominal coin diameters, and visually similar holders are not reliable substitutes for measurement. The cassette is for encapsulated collectibles only. Bare coin or medal contact, archival safety, tarnish prevention, chemical compatibility, and security are not claimed.

Revision `0.1.0-draft.1` is a supportless digital print candidate. The host, both adapters, the exact interface gauge, and both watermark coupons are one-component watertight meshes. All three 3MF packages pass strict inspection. Exact Anycubic Slicer Next 1.3.9.4 jobs are warning-free with the project’s conservative PLA profile. The open-lattice host saves `32.99%` CAD volume against an equally marked continuous-floor proxy. An unscaled R2 Full metriMade identity is recessed under the host, and an R2 Micro identity is recessed under each reusable adapter.

The source market check found a current `50 x 50 x 6.25 mm` square-capsule ecosystem and recurring user complaints about tight extraction, poor finger spacing, unclear size identification, and inconsistent fits. That evidence supports a measured-interface prototype; it does not establish demand. German conversion testing and physical collector trials are still required.

Actual capsule measurement and abrasion, adapter fit, paper-label behavior, loaded drawer cycling, mark legibility, final slicer preview, appearance, safety, and commercial release remain human gates.
