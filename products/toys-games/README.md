# Toys and games

Each child directory is a complete product. Safety and physical evidence remain
product-specific and must not be inferred from another product in this family.

Air, ground and underwater FPV/control component reuse is coordinated in
`FPV-VEHICLE-COMPONENT-MATRIX.md`. That matrix shares an operator ecosystem only
where interfaces and propagation physics permit it; every product retains its
own power, control, safety and physical-validation gates.
